How usage is counted

  • Limit: {{ config.monthlyLimit | number }} potentially billable Street View panorama loads per month (set in src/app/config/usage-config.ts), below the assumed {{ config.assumedFreeMonthlyAllowance | number }} free monthly “{{ config.billingSkuName }}” events.
  • One unit is reserved before the Street View viewer is created. The viewer is then reused for the whole page session.
  • @if (config.countProgrammaticLocationChanges) { Conservative mode: switching the viewer to a different location (new round, previewing another spot) also reserves one unit, because Google does not document whether that is billed. } @else { Switching the viewer to another location does not reserve extra units. }
  • Panning, tilting, zooming and walking around in Moving mode never reserve units.
  • Coverage checks use the Street View metadata service, which Google documents as not billed.
  • Failed loads stay counted; units are only returned when no request could have reached Google.

This counter lives only in this browser. Clearing site data, using another browser or device, or editing storage bypasses it, and it cannot see usage from other apps using the same key. It does not guarantee zero charges — configure Google Cloud quotas and budget alerts as described in the README.
